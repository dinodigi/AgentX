Why the MCP endpoint is stateless. A bare JSON-RPC POST works with no initialize handshake and no session id. Three testers discovered this by probing and each called it an integration advantage — it means a serverless route handler needs no persistent transport and no SDK. It is now documented in get_project_info, with a test asserting the claim is actually true.

Where data lives

the split is the tenancy boundary

CONTROL shared database

projects · workspaces · workspace_members · project_members · collections · project_tokens · project_connectors · project_plugins · plugin_defs · project_schedules · platform_settings · platform_feedback · platform_notices · platform_events · oauth_clients · oauth_codes · webhook_deliveries · audit_log · rate_windows · usage_daily · neon_usage_daily · assets · asset_pointers

TENANT per-project database

entries · entries_trash · entry_versions · entry_changes · jobs · transact_receipts

Plus per-collection DDL derived from the schema: unique indexes, a full-text index, filter indexes, and capacity triggers.

The asymmetry that matters. A tenant database has no foreign key into the control plane's collections table, so the ON DELETE CASCADE that clears entries there does not exist. Deleting a collection has to sweep the tenant side explicitly — including dropping its indexes and triggers, which outlive the rows.

Two read planes that disagree

the platform's defining subtlety

This causes more confusion than anything else on the platform, and it is two separate effects that get mistaken for one.

MCP · /api/mcpDelivery · /api/v1
FreshnessReads fresh. An agent always sees its own writes immediately.Converges within ~15s (cache TTL across a multi-instance fleet).
Row visibilityAll rows.publicFilter + access rules applied.
Field visibilityAll fields.Only publicRead fields.
ConsequenceA row can be readable over MCP yet permanently absent from delivery. That is not a delay — it is a different question being answered.
Correctness gates never read through a cache. A DENY that rests on a stale read is a bug that looks like a policy. Destructive-change checks, relation-target validation, the connector gate and addFields all read fresh from the database.

Guarantees live in the database wherever they can. unique and capacity are an index and a trigger, not application checks — a count-then-insert races, and two callers both see room and both write. That is why the capacity trigger takes a per-key advisory lock before counting.

Query vocabulary

no expression language, ever

One clause shape — {field, op, value} — validated against the collection's fields before any SQL is built. Clauses AND together; {anyOf:[…]} ORs, one level deep. The same vocabulary is reused by publicFilter, events.when, workflow when preconditions, CAS if guards, and schedule sweeps.

OperatorMeaningNote

neSet and differentAn unset field never matches — fail-closed, which publicFilter depends on

containsSubstring, LIKE-escapedLiteral — % and _ match themselves

id (virtual field)Filter by entry ideq ne in only. Fetches a known set in one call instead of N
{hoursAgo} {daysAgo}A relative-time value on a date fieldNegative reaches forward. Makes a live window expressible with no sweep job
A time-varying publicFilter is not edge-cached. A window built from relative time gives a different answer minute to minute, so a cached copy would serve a row past the end of its window. Those collections drop s-maxage deliberately — an exact window costs the CDN hit.

MCP scopes

content.read · content.write · schema.manage · automation.manage · tokens.manage · observability.read

Enforced at one choke point in callTool. scopes = null means full access — the grandfather path, so every token minted before scopes existed still works. A completeness test fails if any of the 60 tools lacks an assignment.

Row & field gates on the delivery API

SettingControls
publicWriteAnonymous POST. Composes with access.write — the two govern different verbs, so "anyone submits, only staff triage" is one collection
access.readpublic · authenticated · owner · {claim,equals} · any-of
access.writeGoverns PATCH/DELETE. owner = own rows; a claim match = staff write on any row

publicFilterRow visibility on delivery. Database-enforced, so a draft cannot reach a reader
Token parentage is a revocation guarantee. Every mint stamps the minting token's row id, and the foreign key cascades — so revoking a compromised token kills everything it minted in the same statement. A foothold cannot survive remediation. An mcp token can only ever mint delivery tokens: strictly weaker than its minter.

Workflow

A state machine over one enum field. initial is enforced on every create path; transitions are the only way the field moves. Gated on who (mcp · operator · client · delivery) and on what (when preconditions), both compiled into the same conditional UPDATE so neither can be raced past.

Schedules

Cron-driven sweeps. A mutate action selects rows by where, then writes each through a compare-and-set, so a row that changed since the query is skipped rather than stomped. Bounded per tick — a sweep is a stream, not a bomb.

A probe result is a point in time, not a live reading. A probe that fails to run — DNS, timeout, an egress blip — no longer overwrites a stored verdict, because an unknown must not replace a known-good. Health carries checkedAt so a reader can tell "broken now" from "failed a check three hours ago".

Infrastructure & domains

push to master deploys

Runtime

Render — blueprint deploy, push-to-master auto-deploys. Cloudflare — CDN with a worker that hashes the bearer token into the cache key, because the same URL serves different projects. Neon — control DB plus one per tenant. UptimeRobot — keyword monitors, since a status-code check is blind to a database outage.

Domains DECIDED, NOT YET MOVED

plugster.dev — platform
api.plugster.dev — delivery + MCP
xvibe.app — XVibe studio
*.myxvibe.com — deployed tenant apps

Tenant apps must not share a registrable domain with a control plane. Otherwise one tenant can set cookies on the parent and an XSS on any deployed app reaches the studio. That is why github.io is not on github.com. The Public Suffix List entry for myxvibe.com — free, but weeks to propagate — is what actually enforces the boundary.
The migration machinery is already built and dormant. Setting SUCCESSOR_API_BASE adds RFC 8594 Deprecation/Sunset/Link headers to every delivery response and a migration note to get_project_info. Not a redirect — a 301 breaks POST bodies and drops auth headers across origins. The old host keeps answering, so it never has to be retired.
